    Add a unit

    On each Colibri PC, download the check-in script, then in PowerShell (Run as administrator) run:

    powershell -ExecutionPolicy Bypass -File .\colibri-checkin.ps1 -Install -Unit "Colibri 19" -Role "Control cabinet"

    Use the unit name exactly as it appears above. The unit shows Online within a minute.
